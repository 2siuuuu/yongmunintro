# 용문동 메인 페이지 HTML 시안

- 목적: 마을 소개 사이트의 분위기와 메인 페이지 구성을 사전 검토한다.
- 범위: 독립 실행 HTML, Pretendard, 반응형 화면, 섹션 이동과 모바일 메뉴.
- 구성: 마을 소개 / 풍경 / 마을 이야기 / 방문 안내.
- 콘텐츠: 지역이 특정되지 않았으므로 문구는 기획 예시이며 풍경은 창작 일러스트로 표현한다.
- 단계: 1. 스타일·구성 설계 2. HTML/CSS 및 메뉴 구현 3. 파일 구조와 링크 검증.
- 후속 구현: 확정 후 React + Vite + Tailwind, 정적 HTML 사전 생성, Hono API, GitHub 및 Cloudflare Pages 구성.
